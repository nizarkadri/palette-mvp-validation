# Implementation Phases

This directory breaks `implementation plan.md` into phase-specific files.

Each phase file contains:

- the phase goal
- how it supports the core product idea
- affected files
- micro-commit-sized implementation steps
- acceptance criteria

Use `micro commit tracker.md` to track progress across phases.
